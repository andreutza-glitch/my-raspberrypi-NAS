# My Raspberry Pi 4 NAS

## Overview

This repository documents the complete process of building a personal Network Attached Storage (NAS) using a Raspberry Pi 4.

The project is intended both as a reliable home storage solution and as a hands-on learning platform for Linux system administration, networking and self-hosted services.

Instead of focusing only on the final setup, this repository documents the design decisions, hardware selection, installation process, configuration steps, encountered issues and lessons learned throughout the project.

## Project goals

- Build a low-power home NAS
- Store photos, videos and documents
- Learn Linux server administration
- Learn storage management
- Learn networking concepts
- Deploy self-hosted services
- Document the entire process

## Planned features

- SSH remote management
- Samba file sharing
- Docker
- Portainer
- Immich
- Jellyfin
- Automatic backups
- Secure remote access
